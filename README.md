# Basic Bot Detection 
Detecting bots on the client-side. This script will analyze bot data & how they interact with a webpage. 
- Looking at: interaction patterns, browser settings, or how a page's layout is displayed.

**Client-side methods:**

(1) CAPTCHAs: puzzless that is simple for humans, but challenging for bots.

(2) Browser Analysis: Analyzing browser configs to determine whether it has bot characteristics, like that of automated script behaviors

(3) Behavioural Analysis: Monitoring mouse movements, keystrokes, and interaction timings to detect bot-like activity.

*This program will only concern itself with on-the-spot bot detection, rather than intrusive checks, such as CAPTCHAs.*
